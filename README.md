# King of the Hill

A chess-piece survival game: you are a lone king holding a hill in the
middle of a big chessboard while enemy pieces march in from every edge.

| Folder | What it is |
|---|---|
| [`godot/`](godot/) | **The game.** A 3D third-person shooter in Godot 4.5: grid movement, enemies move on a beat with telegraphed red squares, tower-defense goal. |
| [`web-prototype/`](web-prototype/) | The earlier turn-based browser prototype (plain JS) used to test the board, hill and wave rules. |

See [`godot/README.md`](godot/README.md) to run the game and
[`godot/DESIGN.md`](godot/DESIGN.md) for the rules and every tunable default.
